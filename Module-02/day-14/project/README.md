# Ethiopian Airlines Booking Page

I rebuilt the layout for a flight search results page.

## What I used
- CSS Grid for the big page layout (header, sidebar, main, footer).
- Flexbox for the navbar, toolbar, and cards.
- The header stays at the top when you scroll.
- The badge on the card uses position: absolute.
- On small screens, the page stacks into one column.

## How to see it
Just open index.html in your browser.
