# BirrWatch

## What it does

BirrWatch is a simple currency converter.

* Converts ETB to other currencies.
* Uses live exchange rates.
* Allows users to add currencies to a watchlist.
* Saves the watchlist and selected currency in localStorage.

## API Used

This project uses the ExchangeRate API:

`https://open.er-api.com/v6/latest/ETB`

ETB is the base currency.

## How to Run

1. Open the project in VS Code.
2. Open the HTML file with Live Server.
3. Enter an ETB amount.
4. Select a currency.
5. Click convert.

An internet connection is required to get the exchange rates.
