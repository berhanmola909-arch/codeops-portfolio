# Dishes Menu App

A simple web application that fetches and displays a list of menu items from an external API using JavaScript.

## Project Structure
* `index.html` - Contains the HTML structure of the page[cite: 1].
* `app.js` - Contains the JavaScript logic for fetching and rendering API data[cite: 1].
* `styles.css` - Contains the CSS styles for UI formatting.

## Features
* Fetches the top 10 items dynamically from JSONPlaceholder API[cite: 1].
* Includes a "Refresh" button to reload the data[cite: 1].
* Displays loading states and basic error handling[cite: 1].

## Getting Started
1. Clone or download this project repository.
2. Open `index.html` in any modern web browser.
3. Click the **Refresh** button to update the list[cite: 1].
